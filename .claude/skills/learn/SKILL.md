# /learn — 教訓の記録（Reflexion）

出来事: **$ARGUMENTS**

## 手順
1. 出来事を「何が起きたか → 教訓（次に何をするか）」の形に言い換える。1 行、120 字以内
2. 信頼度を付ける: 0.3 = 1 回観測した推測 / 0.5 = 原因を特定した / 0.7 = 再現手順がある / 0.9 = 複数回再現しルール化すべき
3. 根拠を書く: 関連ファイル、テスト名、`loop-log.md` の行、コミット
4. `.claude/state/learnings.md` の末尾に追記する:
   `- YYYY-MM-DD | フェーズ N | api または web または loop | <何が起きたか> → <教訓> | 信頼度 0.x | <根拠>`
5. 信頼度 0.7 以上で、既存の rules / skills に書くべき内容なら、その旨を人に提案する（勝手に rules は変えない）
6. `docs/01` の 13 章「実装時に確かめること」に当たる内容なら、確かめた結果として `doc-updater` に反映させる

## 昇格
各フェーズの終わりに `doc-updater` が `learnings.md` を読み、信頼度 0.7 以上を `docs/02_学習ポイント.md` のハマりどころ、または `docs/04_ループエンジニアリング.md` 9 章の「実際」に反映する。
