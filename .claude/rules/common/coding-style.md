# コーディングスタイル（常時適用）

- コメント・コミットメッセージ・ドキュメント・UI 文言は日本語。識別子は英語
- UI 文言とエラーメッセージは要件 2 章の用語（企業 / 管理者 / 拠点 / ワーカー / 募集 / 応募 / 確定 / 却下 / キャンセル / 勤怠 / 報酬）を使う
- 不要な抽象化をしない。api はサービス + Eloquent、web は Server Component + Server Action で足りる。リポジトリ層・状態管理ライブラリ・UI ライブラリは作らない／入れない
- 1 ファイル 300 行を目安に分割を検討する
- デバッグ出力を残さない: api は `dd()` `dump()` `var_dump()` `ray()`、web は `console.log()`（PostToolUse フックが差し戻す）
- マジック文字列を書かない。状態は Enum（api）と API が返す `{value, label}`（web）、設定は `config()` と環境変数
- **第2弾 `../ecc_team/` と第1弾 `../agent_team/` のコードは読まない**（決定14: ゼロから書き直す）。読んでよいのは両者の `README.md` だけ
- パッケージを足さない。使ってよいものは `docs/01_技術仕様_next.md` 1 章の表にあるものだけ
- コマンドは `make` 経由で叩く（`make help`）。`api/` `web/` に入って叩くのは `make` にないものだけ
