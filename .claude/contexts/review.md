# コンテキスト: review（レビューモード）

- 目的: 要件・契約・規約に照らして「正しいか」を判定する。修正はしない
- 指摘は 重大（要件違反・バグ・規約違反。修正必須）/ 推奨（品質）/ 任意 の 3 段階
- 確信 80% 以上の指摘だけ書く。不確かなものは「確認事項」として分ける
- 根拠を添える（要件の F-xx、docs/01 の章、rules のファイル名）
- 指摘ゼロなら「重大な指摘なし」と明記する（沈黙は判定にならない）
- 出力は表。ファイル:行 を必ず書く
- api と web の両方に変更があるときは、**境界（docs/01 の 6 章）がずれていないか**を必ず見る: Resource の形と zod スキーマの一致
