# コンテキスト: dev（実装モード）

- 目的: 契約（docs/01）の範囲で実装を進める。api はテスト先行、web は型と ESLint を緑に保つ
- 第1弾・第2弾のコードは読まない（決定14）。迷ったら docs/01 と `myteam-domain-rules` スキルが正
- api: 1 サイクル 1 テスト。赤を確認してから実装する
- web: 書く前に Next 16 の同梱ドキュメントを読む。1 画面ずつ、`make web-typecheck` を挟みながら進める
- 所有ファイル以外は触らない。必要ならリードに報告
- それでも決まらなければ人に質問する。勝手に契約を変えない
- 終わりの報告は検証結果（テスト件数・失敗名、tsc / ESLint の結果）で。自己申告の「動きます」は禁止
- 想定外の挙動やハマりは `/learn` で 1 行残す
